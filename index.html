❔ Servo Ear 사용법

  1. 📁 프로젝트를 장비·축별로 만듭니다 (예: 1호기 X축). 결과·배경·기준·파라미터가 프로젝트마다 따로 저장됩니다.
  2. 휴대폰을 기계의 고정된 부분(베드·프레임)에 테이프·자석 거치대로 단단히 붙입니다. 소리는 모터·커플링·볼스크루 가까울수록 좋습니다.
    ⚠ 움직이는 테이블·슬라이더 위에는 두지 마세요 (떨어지거나 끼일 수 있음).
  3. 📳 진동 ON → 🎙 마이크 ON (아이폰은 권한 허용) → 모터를 멈춘 상태에서 🔇 배경 측정 (5초).
  4. 낮은 응답성(예: PA09=10)으로 왕복 운전하면서 🚗 기준 운전 — 정상 구동음이 기준이 됩니다. (결과 표의 ⭐로 다른 측정을 기준으로 바꿀 수도 있음)
  5. MR Configurator2에서 응답성 등을 바꾸고 왼쪽 표에도 같은 값을 넣은 뒤(📥 MRC2 불러오기도 가능) 운전 중에 ⏺ 측정 기록.
  6. 응답성을 올려 가며 반복 → 공진이 나오면 노치 필터 후보를 PB13에 넣고 다시 측정 → ✓ 체크 후 📈 겹쳐 보기로 전·후 비교.
  7. 끝나면 📄 보고서(인쇄 → PDF) 또는 📤 공유(ZIP). PC 화면으로 바로 받으려면 🔗 PC 연결.
