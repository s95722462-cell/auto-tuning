# 🔊 Servo Ear — 서보 소리 분석기

MR-J4 오토튜닝 중 나는 **공진음(삑·찡)** 과 **헌팅음(웅웅·덜덜)** 을 마이크로 기록하고, **게인 값(파라미터)별로 비교**해 노치 필터 후보 주파수를 알려 주는 보조 도구입니다.

- MR Configurator2처럼 **파라미터 표**(PA08 · PA09 · PB01 · PB06~PB10 · PB13~PB16) — 넣은 값이 **녹음 이름**이 됩니다 (예: `PA09=16_PB06=7.00_PB13=4500Hz`)
- 🔇 배경 측정(5초, 소리·진동) → 실시간 스펙트럼(20Hz~8kHz, 배경 대비)
- 📳 **진동**: 휴대폰 가속도 센서(약 0.5~30Hz) — 휴대폰을 기계의 고정된 부분에 붙이면 소리와 진동을 함께 저장, 헌팅·저주파 흔들림 판정(배경의 몇 배·주파수)
- ⏺ 측정 기록(5·10·20·30초) → 전체 소리·피크 주파수·판정 (✅ 조용 · ⚠ 약간 · 🔴 공진 의심 · 🟠 헌팅/저주파 의심)
- 📤 **공유**: 휴대폰 공유 창으로 결과 보내기 (아이폰: 카톡·OneDrive·메일·AirDrop / 갤럭시: Quick Share·블루투스·카톡·OneDrive) — CSV만 / +진동 원본 / +녹음 전부
- 결과 표: 듣기 · 스펙트럼 겹쳐 보기 · WAV · 진동 원본 CSV · 전체 CSV(파라미터·진동 값 포함)
- 추천: "응답성 ○까지 안정", 노치 필터 후보 Hz → PB13/PB15, 적용 전·후 비교
- 단축키: `R` 측정 기록, `+`/`−` PA09 응답성

> 소리로 들리는 진동만 보는 **참고 자료**입니다. 최종 판단은 머신 애널라이저·그래프로 하세요.
> 휴대폰은 움직이는 테이블·슬라이더 위에 두지 마세요. 진동은 휴대폰에서만(PC에는 센서 없음).
