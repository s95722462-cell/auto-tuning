# 🔊 Servo Ear — 서보 소리·진동 분석기

MR-J4 오토튜닝 중 나는 **공진음(삑·찡)**·**헌팅음(웅웅·덜덜)**과 **진동**을 휴대폰 마이크·가속도 센서로 기록하고, **게인 값(파라미터)별로 비교**해 노치 필터 후보 주파수를 알려 주는 보조 도구입니다.
주소: https://s95722462-cell.github.io/auto-tuning/

## 기능
- **📁 프로젝트**: 장비·축별로 결과·배경·기준·파라미터를 따로 보관
- **파라미터 표** (MR Configurator2 풍): PA08·PA09·PB01·PB06~PB10·PB13~PB16 — 체크한 값이 **녹음 이름** (`PA09=16_PB06=7.00_PB13=4500Hz`), 📥 **MRC2 파라미터 파일(CSV·TXT) 불러오기**
- **🔇 배경 측정**(정지) · **🚗 기준 운전**(낮은 응답성 운전 = 정상 구동음) → 이후 측정은 **기준 대비**로 판정 (결과 표 ☆로 기준 변경)
- **실시간 스펙트럼**(20Hz~8kHz) + 소리 너무 작음/큼·마이크 입력 없음 경고
- **⏺ 측정 기록**: 소리 판정(✅ 조용 · ⚠ 약간 · 🔴 공진 의심 · 🟠 헌팅/저주파 의심) + 진동 판정(3~30Hz, 0.5~3Hz는 ‘왕복 동작’으로 분리)
- **📈 겹쳐 보기**(최대 5개, 노치 적용 전·후 비교) · **🌈 스펙트로그램**(시간 × 주파수)
- **추천**: 응답성 ○까지 안정, 노치 필터 후보 Hz → PB13/PB15, 적용 전·후 비교
- **📄 보고서**(A4 → PDF) · **📊 CSV** · **📤 공유**(CSV·진동 원본·WAV, ZIP 묶기) · **🔗 휴대폰 → PC 실시간**(측정 숫자만, ntfy.sh 중계)
- **⚙ 설정**: 기기 이름·소리 보정(dB)
- 단축키: `R` 측정 기록, `+`/`−` PA09

> 마이크·휴대폰 센서로 보는 **참고 자료**입니다. 최종 판단은 머신 애널라이저·그래프로 하세요.
